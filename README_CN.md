MoLive 是一个 iOS 应用程序，专门用于 小米动态照片 和 Live Photo 之间的相互转换。它提供了简洁的用户界面和便捷的转换功能。

> 后续开发计划请查看 [路线图](ROADMAP_CN.md)。

[screenshot](image.png)

### ✅ 已实现功能
  - [x] 小米动态照片 转 Live Photo
  - [x] Live Photo 转 小米动态照片  
  - [x] 新旧 Google Motion Photo XMP 与小米 MVIMG 兼容
  - [x] 图片/视频方向归一化与展示帧时间传递
  - [x] 生成后结构、视频、音轨和展示时间验证
  - [x] 批量扫描、失败重试、停止与转换历史
  - [x] 修复 MoLive 旧版生成文件缺失的 JPEG EOI
